# Sleevu — sleevu.app
#
# Política (decidida em 16/11/2026): o TEXTO é aberto de propósito. Sets, cartas
# e decks da comunidade existem pra serem achados na busca e citados por
# assistentes de IA, e os modelos de IA podem aprender com ele: é o canal de
# entrada orgânico do site. Buscador e IA (busca, resposta e treino) leem as
# páginas; o Content-Signal abaixo diz isso no formato do contentsignals.org.
#
# O que fica de fora pra TODO robô são as páginas SEM valor de busca: telas
# pessoais (que só fazem sentido logado e renderizam vazias pro robô) e os
# fluxos de conta. Deixá-las liberadas gastava orçamento de rastreio em casca
# vazia e ainda arriscava indexar título de tela privada.
#
# E o que fica de fora pros robôs de TREINO de IA (o grupo deles, no fim): as
# imagens das cartas e os arquivos de dados. As imagens são das editoras, dos
# artistas e das fontes de onde vêm, e parte delas o Sleevu não pode licenciar
# (o img.sleevu.app tem o robots.txt dele, com o treino fechado). Os dados são
# o catálogo cru do site e do app, que não é uma API pública. Raspar ou extrair
# o catálogo, os preços ou as imagens pra montar outro banco, API, site ou
# serviço é proibido pelos Termos: https://sleevu.app/terms#uso-do-catalogo.

Content-Signal: search=yes, ai-input=yes, ai-train=yes
